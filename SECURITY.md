# Security Policy

## Supported versions

Only releases that pass the release gates in `ROADMAP.md` receive security
support. Development builds and unreleased worktree state are not supported.

## Reporting a vulnerability

Do **not** open a public issue for security vulnerabilities. Report privately
by email to the maintainers (address listed in the repository profile) or via
the GitHub private vulnerability reporting workflow:

`https://github.com/Deko-sudo/Racoon-Typper/security/advisories/new`

Please include:

- the affected version and platform;
- a description of the vulnerability and its impact;
- steps to reproduce, if available;
- whether the issue has been disclosed publicly.

## Handling

The maintainers acknowledge reports within 7 days, verify the report, and
coordinate a fix and disclosure timeline with the reporter. Security fixes are
released as fast as the release gates allow, and the advisory is published
after users have had a reasonable window to update.
